# Changelog

All notable changes to this module are recorded here, one section per release.

## [0.1.0] - 2026-11-20

The Sonoff Zigbee 3.0 USB Dongle Plus (ZBDongle-P, CC2652P), declared as a
coordinator for Mesh (ADR-0003, DEVS-COORD-0001): USB id `10c4:ea60`, its two
`/dev/serial/by-id/` patterns, `needs` host and USB host, and Zigbee2MQTT's
`zstack` adapter. No C code. The page tells the P from the E and says how to plug
it in, from WSL and a UNO Q, and with the serial device's group
(DEVS-COORD-0003).
